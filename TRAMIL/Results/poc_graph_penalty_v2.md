## Notes

- Metric fix during T4: the first v2 run printed NaN for JS(Pi, Pi_A) wherever a Pi row underflowed to exact zeros
  (mu = 0, s >= 2, delta_rms 10-23) on entries where the acoustic adjacency is also zero (0 * log(0/0)). `row_js` now
  treats those entries as contributing 0 (the defined JS value); a test covers it. The full sweep was rerun: every
  non-NaN cell is bit-identical to the first run (max abs diff 0). Criteria and readings were not changed.
- Observation (not a criterion): at s >= 2 the loss half of P2 holds (s = 2: 0.1372 < 0.1394; s = 4: 0.1128 < 0.1130,
  a difference far inside the seed sd), but JS(Pi, Pi_A) rises with s (0.436 -> 0.627): the unpenalized Delta grows
  (delta_rms 5 -> 23) and sharpens Pi without aligning it with the acoustic clusters. Prior-only loss also falls with s
  (1.016 -> 0.113), so at high SNR per-segment features suffice and neighbour aggregation carries little task signal.
